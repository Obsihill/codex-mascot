# Agent Mascot for Windows — 0.2.5

Windows 10/11 x64용 캐릭터 작업 알림 앱입니다. Codex와 Claude Code가 이미 실행 중인 프로젝트 작업을 로컬 기록에서 읽습니다. 새 작업을 시작할 필요가 없습니다.

## 오픈소스 저장소

이 프로젝트는 MIT License로 공개되어 있습니다. 바로 사용하려면 [최신 릴리스](https://github.com/Obsihill/codex-mascot/releases/latest)의 Windows x64 ZIP을 다운로드하세요. .NET 런타임이 포함되어 있습니다. 생성된 배포 파일과 개인 설정은 소스 관리에서 제외합니다. 소스 변경 후에는 `.github/workflows/build-windows.yml`이 테스트와 self-contained Windows 빌드를 자동으로 수행합니다.

```powershell
git clone https://github.com/Obsihill/codex-mascot.git
cd codex-mascot
dotnet run --project src/CodexMascot.App
```

GitHub Actions의 빌드 결과는 workflow의 Artifacts에서 `AgentMascot-Windows-x64`로 내려받을 수 있습니다. 외부 라이브러리의 조건은 `THIRD-PARTY-NOTICES.txt`를 확인하세요.

## 실행

앱과 설치마법사는 한국어·영어를 지원합니다. 앱은 처음 실행 시 Windows 표시 언어가 한국어이면 한국어, 그 외에는 영어를 선택합니다. **설정 → 언어 / Language**에는 현재 적용된 언어가 표시되며 한국어·English 중 선택하면 열린 화면에 즉시 반영됩니다. **확인**은 변경 사항을 저장하고, **취소·X·Esc**는 원래 설정과 언어로 되돌립니다. Windows 자동 시작·연결·Hook 변경은 확인할 때 반영합니다. 두 언어 모두 내장 손글씨 폰트를 사용하며, 개인 마스코트 이름·경로·작업 내용은 번역하지 않습니다.

English: Run `AgentMascot-Setup-<version>-win-x64.exe` to install (the .NET runtime is included), or extract the complete portable ZIP and run `AgentMascot.exe`. On first launch the app follows your Windows display language, with English as the fallback. In **Settings → 언어 / Language**, select **한국어 / English** for an immediate preview. **OK** saves changes; **Cancel**, **X**, or **Esc** restores the original settings and language. The handwritten font is bundled; no font installation is needed.

설치마법사의 **Windows 로그인 시 시작**을 체크하면 로그인 시 트레이로 실행됩니다. 별도의 제거 바로 가기는 만들지 않으며, 기존 바로 가기는 업그레이드 시 정리합니다. 앱 제거는 Windows 설정의 **설치된 앱**에서 가능합니다.

제거 확인 후에는 설치 폴더 안의 설정·로그·등록한 마스코트 복사본도 함께 삭제하며, 빈 설치 폴더를 정리합니다. 설치 폴더 밖의 원본 이미지·영상, Codex/Claude 데이터와 공유 AppData는 삭제하지 않습니다. 알 수 없는 파일이나 잠긴 파일이 남으면 안전을 위해 폴더가 유지될 수 있습니다. 이 동작은 새 설치 파일로 설치/업데이트한 뒤 적용됩니다. 무인 제거도 같은 정리 정책을 사용합니다.

배포 ZIP 전체를 원하는 폴더에 풀고 **AgentMascot.exe**를 실행하세요. DLL/assets/integration 폴더를 EXE와 함께 두세요. 배포판은 .NET 런타임을 포함합니다.

기존 Codex Mascot / Mascot Studio의 표시 이름을 **Agent Mascot**으로 통일했습니다. 소스 프로젝트명, 개인 설정 경로, Hook 및 라이브러리 형식의 내부 식별자는 호환성을 위해 유지합니다. 같은 설치 폴더에 업데이트하면 기존 설정·선택·미디어를 그대로 사용하며, Windows 자동 시작이 켜져 있으면 같은 폴더의 이전 실행 파일을 가리키던 등록만 새 실행 파일로 갱신합니다.

실행 시 Codex·Claude Code 데이터 폴더를 읽고, **설정 왼쪽 감시 프로젝트 선택**에서 체크한 프로젝트의 작업과 Hook 알림만 표시합니다. 목록에는 현재 에이전트별 최근 기록 감시 범위와 진행 중인 채팅이 있는 폴더만 표시되며, 최근 기록 수를 바꾸면 목록도 다시 검색합니다. 예전 기록의 감시 선택은 목록에서 숨겨져도 보존됩니다. 폴더를 클릭해 펼치면 채팅 제목과 도구·세션 ID가 표시되며, 같은 폴더 안에서도 테스트 채팅만 별도로 제외할 수 있습니다. 제목이 없으면 제목 없는 채팅과 세션 ID로 표시합니다. **새 채팅 자동 감시**를 끄면 같은 폴더에 생기는 새 채팅도 직접 체크하기 전까지 제외됩니다. 기존에 제외한 채팅은 자동 감시를 다시 켜도 제외 상태를 유지합니다. 채팅은 도구 종류와 세션 ID로 구분하며 선택은 재실행 후에도 유지됩니다. 선택 변경은 즉시 감시에 반영되며 **모두 감시 / 모두 제외** 아이콘도 사용할 수 있습니다. 확인하면 저장하고 취소하면 창을 열기 전 설정으로 복원합니다. 기존 단일 프로젝트 필터는 해당 경로를 감시하는 설정으로 이전합니다.

같은 창에서 에이전트별 최근 기록 수(기본 100개, 1~1000개)를 정합니다. 수를 줄이면 최초 기록 읽기와 주기적인 파일 확인 비용이 줄지만 새 파일을 찾는 폴더 탐색은 유지됩니다. 이미 진행 중인 작업은 제한에서 밀려나도 계속 감시하며 서브에이전트는 제외합니다. Claude의 기본 폴더는 `CLAUDE_CONFIG_DIR` 또는 사용자 폴더의 `.claude`입니다. 폴더 주소를 비우면 해당 도구의 감시를 끕니다. Codex/Claude를 고르는 별도 활성화 스위치는 없습니다.

1. 메인 화면 오른쪽 아래 **설정 → 연결 → 데스크톱 작업 감시**에서 데이터 폴더가 실제 사용자 계정의 `.codex`인지 확인하세요. `CODEX_HOME` 환경 변수도 인식합니다.
2. 메인 화면 **프로젝트 선택**에서 폴더를 펼쳐 감시할 채팅과 새 채팅 자동 감시 여부를 지정하세요. **확인**을 누르면 저장·적용되고, 취소하면 원래 설정을 유지합니다. 직접 감시를 정지했다면 설정의 감시 시작 버튼을 누른 후 확인으로 재개하세요.
3. 평소처럼 데스크톱 Codex 또는 CLI에서 작업하세요. 새 파일은 약 3초 이내 발견하고, 알려진 파일의 새 이벤트는 약 650ms 간격으로 확인합니다. Codex가 디스크에 기록하는 지연은 별도입니다.
4. 마스코트를 고른 뒤 오른쪽 **테스트**로 재생하세요. 테스트는 실제 작업을 만들거나 작업 결과를 확인 처리하지 않습니다.
5. 메인 창의 X 버튼은 창만 숨기고 감시를 유지합니다. 설정 창의 X·취소는 미리 적용한 변경을 되돌립니다. 작업 목록은 조회 전용이며 선택·결과 확인·ID 복사 버튼은 없습니다. 완전히 종료하려면 트레이의 **종료**를 누르세요.

## 마스코트 라이브러리

메인 화면의 위쪽은 **설치됨**, 아래쪽은 실제 알림에 사용하는 **선택됨** 목록입니다. 마스코트 하나는 대표 이미지와 6개 상태별 미디어(대기·작업 중·확인/승인·완료·실패·중단)를 포함하는 묶음입니다.

- 스튜디오와 설정 창은 종이 배경·연필 테두리의 **Hand-drawn 테마**를 사용합니다. 볼륨·속도·재생시간·위치·테스트/중지·설정·반복·추가/빼기·삭제·초기화 아이콘은 확대해도 선명한 WPF 벡터이며, 별도 폰트 설치나 이미지 다운로드가 필요하지 않습니다. 기존 배치와 숫자 입력·드래그·실행 취소 동작은 유지합니다.
- 스튜디오의 버튼과 항목명에는 **나눔손글씨 펜**을 내장하고 숫자 입력값은 기본 글꼴로 유지합니다. 폰트는 SIL OFL 1.1이며 배포 시 `Fonts/OFL.txt`를 동봉합니다. 정렬 및 상태 드롭다운도 연필 테두리·종이색 목록을 사용하며 설정 초기화는 주황색으로 구분합니다.
- 버튼·카드·드롭다운·체크박스·탭·입력칸은 마우스를 올리면 내부 색상과 배치는 바꾸지 않고 테두리를 진하게 표시합니다. 설치됨/선택됨 카드는 동일한 정사각형이며 대표 이미지 위 하단에 이름을 겹쳐 표시합니다. 카드에 마우스를 올리면 **이미지만 중앙 기준으로 15% 확대**되고 벗어나면 돌아옵니다(0.12초 전환). 확대 이미지는 카드 안에서 잘리며 테두리·이름·+/− 버튼의 크기와 위치는 유지합니다.
- 가로·세로 스크롤바도 종이색 바탕과 연필선 손잡이·화살표를 사용합니다. 손잡이 드래그, 화살표/빈 트랙 클릭, 휠과 키보드 스크롤은 그대로 동작합니다.
- 제목 표시줄과 최소화·최대화/이전 크기로·닫기 버튼도 종이 배경과 손그림 아이콘을 사용하며, 마우스를 올리면 테두리만 진해집니다. 제목 표시줄 드래그·더블 클릭 최대화·창 크기 조절은 유지합니다. 스튜디오의 닫기는 트레이로 숨기고, 설정·등록 등의 보조 창은 해당 창만 닫습니다. 캐릭터 팝업에는 제목 표시줄을 추가하지 않습니다.
- 설치됨 이미지 오른쪽 위의 **+**, 카드 더블 클릭 또는 아래로 드래그하여 추가합니다. 선택됨 이미지 오른쪽 위의 **−**는 해당 항목만 선택 해제합니다. 같은 마스코트도 여러 번 추가할 수 있습니다. 추가된 항목은 각각 독립적인 볼륨·속도·위치·상태별 설정을 가지며, 같은 마스코트끼리는 번호로 구분합니다. 설치됨에서 편집한 설정은 이후 추가할 항목의 기본값이며 이미 선택된 항목은 바꾸지 않습니다. 드래그 중에는 반투명 이미지가 커서를 따라갑니다.
- 선택됨 목록에서는 이미지의 **−**, 카드 더블 클릭 또는 목록 밖으로 드래그하여 해당 복사본 하나만 제거합니다. 다른 복사본과 파일은 삭제하지 않습니다. 영역 안에 놓거나 Esc로 취소하면 유지합니다. 선택된 항목이 없으면 캐릭터와 알림 소리를 재생하지 않습니다.
- 설치됨 목록의 **삭제**는 확인 후 마스코트를 설치·선택 목록에서 모두 제거합니다. 마스코트 폴더와 이미지·영상 파일은 보존합니다. **−**는 선택만 해제하고, **삭제**는 등록을 해제합니다.
- 이벤트가 발생하면 선택된 항목 중 해당 이벤트의 재생을 켠 **모든 마스코트를 동시에 재생**합니다. 영상·소리·위치는 각 항목마다 독립적입니다. 위치가 같으면 겹쳐 보이므로 각 항목의 위치를 따로 정하세요. 같은 알림을 클릭해 확인하면 해당 알림의 마스코트를 함께 닫습니다.
- 오른쪽의 **전체**에는 볼륨(0–200%, 신규 기본값 100%), 재생 속도(0.25–3배), 위치·크기가 있습니다. **상태별 설정**에서는 대기 중·작업 중·확인/승인 필요·응답 완료·실패·중단을 개별 편집하며 **재생**과 **반복**도 설정합니다. **전체로** 돌아왔을 때 상태별 값이 다르면 해당 항목에 `??`가 표시됩니다. 전체에서 값을 바꾸면 현재 항목의 그 설정만 모든 상태에 적용합니다.
- 볼륨·재생 속도·위치 창의 X/Y는 **줄 전체를 좌우로 드래그**해 조절합니다. 마우스를 올리면 ↔ 커서가 나타나며 Shift를 누르면 정밀 조절합니다. 클릭하면 숫자를 직접 입력하고 Enter 또는 다른 곳 클릭으로 적용합니다. Esc는 입력·드래그를 취소합니다. 드래그는 놓을 때 한 번 저장하므로 한 번의 Ctrl+Z로 되돌립니다. 숫자 입력 중 Ctrl+Z는 입력한 텍스트만 되돌립니다.
- 볼륨·재생 속도 칸은 설정 범위에서의 비율만큼 연한 회색으로 채워집니다. 볼륨 0–200%는 0–100% 채움(100% 볼륨은 절반), 속도 0.25–3배는 0–100% 채움입니다. 드래그·값 적용·실행 취소에 따라 갱신하며 상태별 값이 달라 `??`일 때는 채움을 숨깁니다. 마우스를 올려도 채움 색은 바뀌지 않습니다.
- **이미지 재생시간**은 **상태별 설정**에서 재생이 켜져 있고 이미지가 지정된 상태를 선택했을 때만 표시합니다. 전체 설정과 영상 상태에서는 숨깁니다. 숫자 줄에서 초 단위로 입력·드래그하며(0–600초, 0은 시간 제한 없음), 현재 이미지의 시간만 변경합니다. 정지 이미지와 GIF/WebP에 적용하고 각 상태의 저장된 시간은 유지합니다. **클릭해야 닫힘**을 켠 상태는 재생시간보다 클릭 대기를 우선합니다. 일반 알림의 아주 짧은 양수 시간은 최소 0.2초로 표시합니다.
- **설치됨** 오른쪽에서 이름(오름차순), 설치 날짜(최신순), 선호순으로 정렬합니다. 선호는 앱 실행 중 해당 마스코트가 **선택됨**에 머문 누적 시간이며 같은 마스코트의 중복 선택은 한 번만 셉니다. 동점은 이름순입니다. 30초마다 기록하고 앱 종료 시 저장하며 종료 중인 시간은 세지 않습니다. 기존 항목의 알 수 없는 설치 날짜는 마지막에 놓고, 날짜 동점은 기존 순서를 유지합니다. 정렬은 선택됨의 순서를 바꾸지 않습니다.
- **소리** 체크박스 대신 볼륨 **0%**로 WAV/MP3 알림과 MP4 내장 소리를 끕니다. 기존 음소거 설정은 0%로 전환합니다. 100% 초과 음량은 NAudio로 소프트웨어 증폭하며 큰 원본은 소리가 찌그러질 수 있습니다. 증폭 영상은 내장 오디오를 무음으로 하고 별도 오디오 스트림을 영상 시작·반복·정지에 맞춰 재생합니다. 속도를 바꾸면 별도 오디오의 음높이도 바뀝니다. 코덱이나 출력 장치 오류는 화면 하단 또는 수신 로그에 표시합니다.
- **위치 크기 변경**을 누르면 한 줄의 X/Y 좌표와 그 아래 **크기 조절바(40–300%)**, 드래그 가능한 마스코트가 바로 뜹니다. 크기 바는 좌우 드래그·숫자 입력을 지원하고 미리보기에 즉시 반영되며 놓을 때 한 번 저장합니다. Esc는 드래그를 취소하고 Ctrl+Z는 저장된 변경을 되돌립니다. 좌표도 직접 입력하거나 마스코트를 드래그해 바꿀 수 있습니다. 창을 닫으면 배치 모드가 끝납니다. 좌표는 전체 바탕화면 기준의 물리 픽셀 값이며 음수 좌표를 지원하고 화면 밖 위치는 보정합니다. 전체에서는 해당 마스코트의 모든 상태를, 상태별에서는 그 상태만 변경합니다. 중복 선택한 마스코트도 크기를 따로 저장합니다. 기존 개별 크기가 없는 라이브러리는 이전 공통 크기를 유지하며, 초기화하면 100%로 돌아갑니다. 크기가 서로 다르면 바에 `??`를 표시합니다.
- 변경은 자동 저장되고 다음 알림부터 적용됩니다. 재생 중인 항목을 사용 목록에서 빼거나 현재 이벤트를 제외하면 해당 팝업을 숨깁니다.
- 대표 이미지는 설치됨·선택됨 카드와 **전체**의 오른쪽 미리보기에 표시하며, 재생 상태로 선택할 수 없습니다. 카드 이름은 이미지 위의 흰색 반투명 바에 표시합니다. 상태별 설정에서는 고른 상태의 이미지를 봅니다. 영상 미리보기는 무음입니다.
- **전체 → 테스트**는 대기·작업 중·확인/승인·완료·실패·중단을 순서대로 재생합니다. 각 영상은 반복 설정과 관계없이 한 번 끝까지 재생하고 다음 상태로 넘어갑니다. 이미지는 설정한 시간(최대 10초), 무제한 이미지는 2초씩 표시합니다. 현재 상태는 하단에 표시하며 모두 끝나면 자동 종료합니다. 중지 버튼이나 캐릭터 클릭은 남은 순서까지 취소합니다. 저장된 반복·재생 제외 설정은 바꾸지 않습니다.
- **상태별 → 테스트**는 해당 상태만 재생합니다. 영상은 시간 제한 없이 끝까지 재생한 뒤 자동 종료하며, 반복을 켜면 직접 중지할 때까지 반복합니다. 이미지 테스트는 설정한 재생시간에 맞춰 멈추되 최대 10초이고, 무제한 이미지도 테스트에서는 10초 후 멈춥니다. 영상 재생 실패 시 오류를 표시하고 테스트를 종료합니다. 모든 테스트는 해당 상태의 볼륨·랜덤 소리를 따르며 재생 제외 상태도 테스트할 수 있습니다.
- 전체의 **설정 초기화**는 현재 편집 중인 항목만 기본값(볼륨 100%, 속도 1배, 반복 끔, 오른쪽 아래 위치, 대기 이외 이벤트 재생)으로 되돌립니다. 미디어·이름·선택 목록·다른 항목은 유지합니다. 초기화는 **Ctrl+Z**로 취소할 수 있습니다.
- 설치됨·선택됨 사이의 구분선을 드래그하면 높이 비율을 조절합니다. 라이브러리 설정·선택·등록·삭제·위치·높이 비율은 **Ctrl+Z**로 실행 취소하고 **Ctrl+Y** 또는 **Ctrl+Shift+Z**로 다시 실행합니다. 변경 내역은 **마스코트 등록·설정 버튼 왼쪽의 같은 줄**에 표시합니다. 긴 문구는 말줄임하며 마우스를 올리면 전체를 볼 수 있습니다. 이력은 현재 실행 동안 최대 100단계이며 연결·Hooks 등 앱 공통 설정은 포함하지 않습니다. 등록·삭제 취소는 목록만 복원하며 미디어 파일을 지우지 않습니다.
- **마스코트 등록**은 **라이브러리** 탭으로 열립니다. **라이브러리 폴더 선택**으로 mascot.json이 든 폴더를 고르거나 폴더·mascot.json을 창에 끌어 놓으세요. 이름·대표 이미지를 확인하고 **등록**하면 6개 상태 미디어와 기본 설정을 함께 복사합니다. 선택됨에는 자동으로 넣지 않습니다. 같은 라이브러리를 다시 가져와도 새 ID로 등록하여 기존 항목을 덮어쓰지 않으며 Ctrl+Z로 취소할 수 있습니다. 읽기·미리보기·취소는 파일을 복사하지 않습니다. 손상된 설정, 누락 미디어, 폴더 밖 경로·심볼릭 링크는 거부합니다.
- **직접 만들기** 탭에서는 이름, 대표 이미지, 6개 상태의 이미지·영상과 선택적 **WAV/MP3 소리**를 개별 지정합니다. 대표 이미지는 PNG/GIF/WebP, 상태별 미디어는 MP4 등의 영상도 지원합니다. 이미지·영상·소리 선택은 등록 화면에서 하며 **상태별 설정**에는 미디어 변경·소리 선택/제거 버튼이나 소리 파일 표시를 두지 않습니다. 파일은 마스코트별 폴더에 복사되고 취소 시에는 복사하지 않습니다. 영상 코덱 지원 여부는 Windows 환경에 따라 다릅니다.
- 새 배포의 기본 라이브러리는 **기존 마스코트**(`assets/images`)와 **MasCat**(`assets/MasCat`) 두 종류이며, **MasCat이 기본 활성화**됩니다. 각각 `main.png` 대표 이미지와 대기·작업 중·확인/승인·완료·실패·중단 이미지가 들어 있습니다. 기존 봇·고양이·유령·별·새싹·젤리 샘플은 새 기본 목록에서 제외했습니다. 이미 저장된 개인 라이브러리·선택·미디어는 업데이트로 삭제하거나 덮어쓰지 않습니다.
- 기존 단일 파일 라이브러리는 설정·선택을 보존하며 묶음으로 전환됩니다. 직접 등록했던 단일 파일은 각 상태 슬롯에 같은 파일을 넣습니다. 구성을 바꾸려면 새 묶음을 등록할 수 있습니다.
- 설정 창은 손그림 테마의 **일반 / 알림 / 연결 / 정보 / 언어** 탭으로 구성됩니다. 일반에는 Windows 시작·항상 위·대기 표시, 알림에는 앱 열기, 연결에는 감시 상태와 데이터 폴더, 정보에는 버전·글꼴 정보를 표시합니다. 언어·화면 변경은 미리 적용하며 확인하면 저장하고 취소하면 복원합니다. 폴더·채팅별 포함·제외, 새 채팅 자동 감시, 최근 기록 수는 설정 왼쪽 **프로젝트 선택**에서 변경합니다. 클릭 통과와 전역 완료 유지 항목은 제거했으며, 클릭 대기는 마스코트의 상태별 설정에서 관리합니다. 소리·에셋·구형 테마 ZIP 메뉴는 제거했으며, 미디어와 소리는 마스코트 라이브러리에서 관리합니다.
- 소리는 마스코트의 **각 상태마다 별도로 저장**합니다. 등록 화면에서 WAV/MP3를 여러 개 선택하면 **매 재생마다 같은 확률로 하나를 랜덤 선택**하며, 연속으로 같은 소리가 나올 수도 있습니다. 테스트에도 동일하게 적용되고 선택된 결과가 원래 목록을 바꾸지는 않습니다. 여러 소리 파일도 전부 라이브러리 폴더에 복사합니다. 구형 단일 `sound` 형식과 새 `sounds` 목록 모두 지원하며 목록이 우선입니다. MasCat의 완료·실패·확인/승인에는 제공된 야옹 WAV 7개가 지정되고 나머지 상태와 기존 마스코트는 무음입니다.
- 볼륨 0%는 해당 소리와 영상 소리를 끕니다. 영상에 별도 소리를 지정하면 내장 소리를 대신하며, 제거하면 영상 자체 소리로 돌아갑니다. 상태 전환 시 소리는 한 번 재생하고 팝업을 닫거나 테스트를 중지하면 함께 멈춥니다. 기존 공통 소리·음소거는 최초 전환 시 개별 소리·볼륨으로 옮기고 원본 설정을 백업합니다.
- 알림 소리는 재생 전에 메모리로 미리 디코딩하고 출력 버퍼를 넉넉히 잡아 PC가 바쁠 때도 끊기지 않고 재생합니다. 8MB를 넘는 긴 사운드만 기존처럼 스트리밍하며, 볼륨·속도·시작 위치 설정은 그대로 적용됩니다.

라이브러리 선택과 개별 옵션은 `config/library.json`, 선호 누적 시간은 `config/library.usage.json`에 별도로 저장합니다. 실행 취소는 선호 시간을 되돌리지 않습니다. 개인 설정이므로 Git에 포함하지 않습니다. 구형 테마 ZIP은 프로그램의 색상 테마가 아닌 공통 마스코트 설정·에셋 묶음이었으며, 이제 폴더형 마스코트 라이브러리를 사용합니다.

마스코트는 실행 파일 옆 `library/mascot-<ID>/`에 폴더형으로 저장합니다. `mascot.json`에는 이름·대표 이미지·6개 상태 이미지/영상·소리·기본 재생 설정이 있고, `media/`에 해당 이미지·영상·WAV/MP3 파일이 함께 들어갑니다. 매니페스트의 파일 경로는 폴더 기준 상대 경로입니다. 같은 원본을 여러 상태에서 쓰면 한 번만 복사하고, 중복 선택도 미디어를 공유합니다. 선택된 복사본마다 다른 소리·볼륨·위치 등은 위의 라이브러리 인덱스에 별도로 저장합니다. 내장 샘플도 실제 PNG·WAV 파일로 저장하고 영상은 오디오를 포함한 원본 바이트를 그대로 복사합니다.

기존 목록은 첫 실행 시 폴더형으로 전환하며, 이전 `library.json`은 `.before-folders-…` 백업을 남깁니다. 이전 이미지·영상 원본은 지우지 않습니다. 누락 파일 등으로 전환에 실패하면 기존 목록을 유지하고 오류를 표시합니다. 폴더의 `mascot.json`은 설치됨의 기본 설정 변경에 맞춰 갱신됩니다. 현재 설치 목록은 인덱스가 관리하므로 외부 폴더 복사만으로 자동 등록되지는 않습니다.

## 상태의 의미

- **작업 중**: 실제 `task_started` 또는 진행 이벤트를 관찰했습니다.
- **응답 완료**: `task_complete` / Hook `Stop`을 관찰했습니다. 요청한 목표 달성이나 코드 검증 성공을 보증하는 뜻은 아닙니다.
- **중단**: `turn_aborted` / Hook `Interrupt`를 관찰했습니다.
- **확인/승인 필요**: Hook 또는 앱이 시작한 app-server의 요청입니다. 외부 데스크톱 작업의 승인/답변은 원래 Codex에서 합니다.
- **실패**: 앱이 시작한 작업의 명시적인 실패 이벤트입니다. 도구 경고를 전체 작업 실패로 판단하지 않습니다.
- **상태 확인 필요**: 진행 중이던 기록이 5분간 갱신되지 않았거나 연결이 끊겼습니다. 느린 작업도 여기에 포함될 수 있으며 완료로 추측하지 않습니다.
- **대기 중**: 활성 작업과 미확인 결과가 없습니다.

우선순위는 승인/질문 → 실패 → 미확인 응답 완료 → 미확인 중단 → 작업 중 → 확인 필요 → 대기입니다.
같은 집계 상태가 유지되는 동안 팝업·소리를 반복하지 않습니다. 오래된 결과는 앱 시작 시 알림을 띄우지 않습니다.
캐릭터 클릭은 알림을 확인 처리하지만 **원래 도구의 승인 요청을 승인하지 않습니다**.

## 승인·질문 추가 알림: Hooks (자동)

기록 감시만으로 시작/응답 종료/중단을 사용할 수 있습니다. 세부 승인 알림이 필요하면:

1. 감시가 시작되면 주소가 지정된 도구의 존재하는 데이터 폴더에 Hook이 자동 등록됩니다. 켜기·끄기 토글은 없습니다.
2. Codex의 `hooks.json`, Claude의 `settings.json`에 Mascot 전달 스크립트가 병합됩니다. 기존 설정은 보존하고 변경 시 `.mascot-backup-날짜` 파일을 만듭니다. 정상 등록된 파일은 반복해서 수정하지 않습니다.
3. Codex CLI의 `/hooks`에서 Mascot Hook 내용을 검토하고 신뢰하도록 설정합니다. 앱은 신뢰 검토를 우회하지 않습니다. 기존 작업은 다시 열어야 설정이 적용될 수 있습니다.
4. Codex에서 새 메시지를 보내고 Mascot의 **Hook 수신 확인** 문구를 확인합니다. 설정 저장과 실제 이벤트 수신은 다릅니다.

`UserPromptSubmit / PermissionRequest / PreToolUse(request_user_input) / PostToolUse / Stop / Interrupt / SessionEnd`를 처리합니다.
Hook은 승인 정책이나 프롬프트를 변경하지 않으며 실패해도 Codex를 막지 않습니다. 원문 프롬프트·명령·응답은 저장하지 않고 작업 ID/작업 폴더/이벤트명/시각/도구명만 전달합니다.
전달 파일 위치: `%LOCALAPPDATA%/CodexMascot/events`. 앱이 꺼져 있던 기간의 이벤트는 다음 실행에서 재알림하지 않습니다.
채팅을 선택 해제하면 해당 채팅의 기록·Hook 이벤트 모두 알림에서 제외합니다. 같은 폴더의 다른 채팅은 계속 감시할 수 있으며, 폴더 전체 감시를 해제하면 하위 채팅도 모두 제외합니다. 원래 도구의 Hook 설정과 신뢰 정책은 유지됩니다. 프로젝트 경로가 없는 Hook은 이미 알려진 같은 도구의 세션 경로로 판별하며, 경로를 알 수 없으면 감시 목록에 추가하지 않습니다.

**중요한 범위:** JSONL 기록 형식은 공식적으로 안정된 외부 API가 아닙니다. Codex 업데이트에 따라 어댑터 수정이 필요할 수 있습니다. 클라우드·다른 컴퓨터의 작업, 이 PC에 기록되지 않는 작업, 기록되지 않는 모든 승인/실패를 완전히 감시한다고 보장하지 않습니다. Hook이 전달되지 않으면 해당 승인 상태를 추측하지 않습니다.
작업 식별자와 Hook의 세션 식별자가 다른 Codex 버전에서는 매핑을 추가로 조정해야 할 수 있습니다.

## 캐릭터·사운드·위치

기본 위치는 **기본 모니터 오른쪽 아래**입니다. 일반 알림은 드래그해도 이동하지 않습니다. **위치 크기 변경**의 X/Y는 이미지·영상의 **중앙 좌표**입니다. 크기를 바꿔도 중앙과 표시 좌표는 고정됩니다. 기존 왼쪽 위 기준 위치는 화면상 위치를 유지하고, 처음 편집할 때 중앙 기준으로 저장합니다. 창을 열기만 하면 저장하지 않습니다. 드래그 좌표는 실시간 표시하고 놓으면 저장하며 창을 닫으면 배치 모드가 종료됩니다. 중앙 고정을 위해 가장자리에서는 큰 이미지 일부가 화면 밖으로 나갈 수 있으며, 모니터가 없어졌다면 중앙을 가까운 화면 가장자리로 보정합니다. 마스코트는 화면 상단으로 드래그하거나 최대화 명령을 보내도 전체화면으로 바뀌지 않습니다. 메인 창의 최대화·복원은 그대로 사용할 수 있습니다.

창을 닫으면 백그라운드에서 계속 실행합니다. Windows 알림 영역(숨겨진 아이콘)의 마스코트 아이콘을 **왼쪽 더블클릭**하면 Agent Mascot을 열며 최소화된 창도 복원합니다. 우클릭 메뉴의 **Agent Mascot 열기**도 같은 동작이고, 완전히 끝내려면 **종료**를 선택합니다.

상태별 **확인하면 닫힘**을 켜면 재생시간이 지나도 알림을 유지합니다. 마스코트를 클릭하거나 해당 Codex/Claude 데스크톱 창을 활성화하면 확인 처리하고 알림을 닫습니다. 기본 두 마스코트는 응답 완료·확인/승인 필요·실패만 켜져 있습니다. 끄면 해당 상태의 재생시간 또는 도구 창 활성화에 따라 자동으로 닫힙니다. 알림을 닫아도 실제 승인 대기 상태는 유지됩니다. 캐릭터에 별도 × 버튼은 없습니다. 상태의 **재생**을 끄면 볼륨·속도·이미지 재생시간·위치 크기·반복·테스트 조작이 숨겨지며 저장된 값은 유지됩니다. MasCat의 기본 이미지 재생시간은 모든 상태에서 2초입니다.

**팝업 클릭 시 Codex 데스크톱 창 열기**는 Codex와 Claude 모두에 적용됩니다. 알림에 해당하는 앱의 실행 중인 데스크톱 창을 앞으로 가져오고 최소화 상태는 복원합니다. 특정 작업 탭까지 전환하지는 않습니다. 창을 찾지 못하거나 옵션을 끄면 Mascot 작업 창을 엽니다. Windows가 전환을 제한하면 작업 표시줄 아이콘으로 알립니다. 터미널/VS Code의 CLI 창은 전환 대상이 아닙니다.

스튜디오의 **테스트**로 편집 중인 마스코트를 재생할 수 있습니다. 테스트 팝업을 클릭해도 실제 작업 결과를 확인 처리하거나 Codex / Claude 창을 열지 않습니다.

기존 설정에 새 항목이 없으면 기본값으로 적용됩니다. JSON에서는 `global.keepCompletedVisibleUntilClick`, `global.bringCodexToFrontOnClick`으로 변경할 수 있습니다.

- GIF, PNG, WebP (투명 배경 지원). GIF/WebP 애니메이션은 프레임별 시간을 반영합니다.
- 정적 이미지의 스프라이트 시트: 기존 테마 JSON의 가로/세로 칸과 칸당 시간 설정을 지원합니다. 기본 1×1.
- WAV/MP3. 마스코트별·상태별 볼륨을 사용하며 선택된 마스코트들은 각자의 소리를 동시에 재생합니다.
- 스튜디오의 대표·상태별 미리보기와 테스트/중지 버튼.
- 테스트도 음소거 설정을 따릅니다. 화면의 재생 시작은 미디어 플레이어가 파일을 연 것을 뜻하며 실제 스피커 소리는 직접 확인하세요.
- 마스코트 등록 시 이미지·영상을 `library/mascot-<ID>/media/`로 복사합니다. 원본을 삭제해도 복사본을 사용합니다.
- 이미지 누락은 상태별 기본 PNG, 디코딩 실패는 내장 기호로 대체합니다.
- 이미지·영상·소리가 포함된 폴더형 라이브러리 가져오기. 마스코트 재생 설정 초기화는 스튜디오에서 실행합니다.
- 크기/항상 위/상태별 클릭 대기/대기 캐릭터/Windows 로그인 시 시작.

```text
AgentMascot/
  AgentMascot.exe
  assets/images/idle.png, running.png, attention.png, completed.png, failed.png, interrupted.png
  assets/sounds/attention.wav, completed.wav, failed.wav
  config/mascot.json                  ← 첫 실행 시 생성/자동 저장
  config/library.json                 ← 라이브러리 선택·마스코트별 옵션
  config/library.usage.json           ← 선호 누적 시간
  library/mascot-<ID>/mascot.json      ← 마스코트 묶음 정보·기본 설정
  library/mascot-<ID>/media/           ← 대표 이미지·상태별 이미지/영상
  config/connection-status.json       ← 연결·작업 상태 진단
  config/events.jsonl                 ← 원문 없는 상태 전환 기록
  integration/Send-MascotEvent.ps1
```

설치 폴더에 쓰기 권한이 없으면 `%LOCALAPPDATA%/CodexMascot/data`에 설정과 에셋을 저장합니다.

새 작업 실행·승인·중단은 원래 Codex/Claude 앱에서 진행합니다. Agent Mascot은 기존 작업을 감시하고 알림만 표시합니다.

## 검증 및 빌드

.NET SDK 9.0.306 이상 안정 버전, target .NET 8 WPF.

```powershell
dotnet build CodexMascot.sln -c Release
dotnet run --project tests/CodexMascot.Core.Tests -c Release
dotnet run --project tests/CodexMascot.App.Tests -c Release
dotnet publish src/CodexMascot.App -c Release -r win-x64 --self-contained true -o Release
```

Core 테스트는 중복/지연 이벤트, 여러 승인, 우선순위, 초기 기록 복원, JSONL 부분 쓰기/잘림, 실제 형식의 파일 추가 이벤트를 확인합니다.
App 테스트는 GIF 프레임 시간, WebP, 스프라이트, 테마, 손상 JSON, Hook 설정 병합/해제/전달, 숫자형 승인 ID, 프로세스 종료 시 요청 해제를 확인합니다.
실제 데스크톱 기록을 읽는 감시와 실행 화면을 확인했습니다. 실제 Codex에서 신뢰된 Hook을 발신하는 종단 검증과 다양한 DPI/모니터 하드웨어 조합은 별도입니다.

사용 라이브러리 조건은 THIRD-PARTY-NOTICES.txt를 참고하세요.
